# 03. Архитектура

## Обзор

Выбран архитектурный паттерн **PCMEF** в распределённой клиент-серверной конфигурации.

## Обоснование выбора

1. **Разделение ответственности** — UI, бизнес-логика, данные и интеграции изолированы
2. **Распределённая архитектура** — мобильный клиент + Spring Boot сервер + внешние API
3. **Масштабируемость** — возможность добавления web-клиента, микросервисов
4. **Тестируемость** — каждый слой тестируется независимо
5. **Офлайн-поддержка** — MobX + AsyncStorage на клиенте

## Отвергнутые альтернативы

- **MVC** — перегруженные контроллеры, плохая изоляция бизнес-логики
- **Clean Architecture** — избыточная сложность для учебного проекта
- **Монолитное мобильное приложение** — невозможна централизованная синхронизация
