# 01. Бизнес-модель

## Обзор этапа

Этап бизнес-моделирования определяет предметную область системы, ключевые бизнес-процессы, стейкхолдеров и экономическое обоснование разработки.

## Проблема

Для работы со счетами у разных брокеров инвестору требуется множество фирменных приложений, что приводит к сложностям с анализом и автоматизацией операций.

## Решение

Разработка системы Investment Aggregator Platform, позволяющей агрегировать счета, открытые у разных брокеров, проводить комплексный анализ по всем счетам сразу.

## Цели

- Сократить время анализа на 40%
- Снизить ошибки и неточности при множественных счетах на 90%
- Автоматизация 80% рутинных операций
- Мобильный доступ для инвесторов

## Ключевые показатели

- Время обработки данных по счёту < 5 минут
- Удовлетворённость пользователей > 85%
- Окупаемость < 12 месяцев
