## 1. Введение

**InvestAgg** — мобильное приложение для агрегации брокерских счетов. Позволяет подключить счета у разных брокеров и управлять ими из единого интерфейса: просматривать аналитику портфеля, выставлять торговые заявки, получать уведомления и генерировать отчёты.

### Основные возможности

- Единый портфель по всем брокерам с расчётом P&L (прибыль/убыток)
- Подключение нескольких брокерских счетов
- Выставление ордеров BUY/SELL
- Автоматическая синхронизация данных каждые 15 минут
- Уведомления об исполнении ордеров и ошибках
- Генерация отчётов в формате PDF/CSV

## 3. Регистрация и вход

### 3.1. Регистрация нового пользователя

1. Откройте приложение InvestAgg.
2. На экране входа нажмите ссылку **"Don't have an account? Register"**.
3. Заполните форму:
   - **Email** — действующий адрес электронной почты.
   - **Password** — минимум 8 символов.
4. Нажмите кнопку **"Register"**.
5. После успешной регистрации выполняется автоматический вход в систему.

**Возможные ошибки:**
- *"User with email already exists"* — такой email уже зарегистрирован. Используйте другой адрес или войдите.
- *"Password must be at least 8 characters"* — пароль слишком короткий.

### 3.2. Вход в существующий аккаунт

1. Введите **Email** и **Password**.
2. Нажмите **"Sign In"**.
3. JWT-токен сохраняется автоматически — при следующем запуске приложения повторный вход не требуется.

### 3.3. Выход из аккаунта

При выходе из аккаунта токен удаляется из хранилища устройства. Для выхода используйте соответствующий пункт в настройках приложения.

### 3.4. Восстановление сессии

При каждом запуске приложение автоматически проверяет наличие сохранённого токена. Если токен действителен — пользователь попадает на главный экран. Если токен истёк (TTL — 1 час) — приложение показывает экран входа.

## 4. Портфель и аналитика

### 4.1. Просмотр портфеля

Вкладка **"Portfolio"** — главный экран приложения.

**Отображаемые данные:**
- **Total Value** — общая стоимость всех активов в рублях.
- **P&L (Profit & Loss)** — прибыль или убыток по портфелю:
  - Зелёный цвет — портфель в прибыли.
  - Красный цвет — портфель в убытке.
- **Процент P&L** — изменение стоимости в процентах.

### 4.2. Список активов

Под заголовком портфеля отображается список карточек активов. Каждая карточка содержит:

| Поле | Описание |
|---|---|
| Тикер | Биржевое обозначение актива (например, SBER) |
| Стоимость | Текущая стоимость позиции |
| P&L | Прибыль/убыток по конкретному активу |
| Qty | Количество акций/лотов |
| Avg / Now | Средняя цена покупки / текущая рыночная цена |

### 4.3. Обновление данных

Потяните список вниз (pull-to-refresh) для загрузки актуальных рыночных цен. Данные также обновляются автоматически при каждом открытии экрана.

## 5. Управление брокерскими счетами

### 5.1. Просмотр подключённых счетов

Вкладка **"Accounts"** отображает список всех привязанных брокерских счетов.

Для каждого счёта показано:
- Название брокера
- Номер счёта
- Статус: **ACTIVE** (зелёный), **REVOKED** (красный), **ERROR** (оранжевый)
- Дата последней синхронизации

### 5.2. Подключение нового счёта

1. Нажмите кнопку **"+ Connect Broker"** внизу экрана.
2. Выберите брокера из списка (отображаются chip-кнопки).
3. Введите **номер счёта** (Account Number).
4. Введите **API-токен** (Broker API Token) — токен доступа, полученный от брокера.
5. Нажмите **"Connect Account"**.

После успешного подключения счёт появится в списке со статусом ACTIVE, и будет запущена первичная синхронизация данных.

**Возможные ошибки:**
- *"Invalid broker token"* — токен не прошёл валидацию на стороне брокера. Проверьте правильность ввода.
- *"Account already connected"* — этот счёт уже привязан к вашему аккаунту.

### 5.3. Синхронизация данных

Нажмите кнопку **"Sync"** на карточке счёта для ручной синхронизации. Система загрузит актуальные позиции и транзакции от брокера.

Автоматическая синхронизация выполняется каждые 15 минут.

### 5.4. Отключение счёта

1. Нажмите кнопку **"Disconnect"** на карточке счёта.
2. Подтвердите действие в диалоговом окне.

Отключение выполняет «мягкое удаление» — данные сохраняются в системе, но счёт становится недоступным.

## 6. Торговые операции

### 6.1. Просмотр ордеров

Вкладка **"Orders"** отображает историю всех торговых заявок.

**Цветовая индикация статусов:**

| Статус | Цвет | Описание |
|---|---|---|
| PENDING | Оранжевый | Заявка ожидает исполнения |
| FILLED | Зелёный | Заявка исполнена |
| CANCELLED | Серый | Заявка отменена пользователем |
| REJECTED | Красный | Заявка отклонена брокером |

Каждая карточка ордера содержит: тикер, направление (BUY/SELL), количество, цену, итоговую сумму, дату размещения и исполнения.

Список поддерживает бесконечную прокрутку — при достижении конца подгружаются следующие ордера.

### 6.2. Создание нового ордера

1. Перейдите к форме создания ордера через экран счетов.
2. Убедитесь, что выбран правильный счёт (отображается в заголовке формы).
3. Заполните поля:
   - **Ticker** — тикер актива (например, SBER, YNDX, GAZP).
   - **Direction** — нажмите **BUY** (покупка) или **SELL** (продажа).
   - **Quantity** — количество лотов/акций.
   - **Price** — лимитная цена за единицу.
4. Проверьте строку **"Total"** — итоговая сумма рассчитывается автоматически.
5. Нажмите **"Place BUY Order"** (или "Place SELL Order").

После создания ордер появится в списке со статусом PENDING.

### 6.3. Отмена ордера

Для ордеров в статусе PENDING доступна кнопка **"Cancel Order"**:
1. Нажмите **"Cancel Order"** на карточке ордера.
2. Подтвердите отмену в диалоговом окне.

Ордера в статусах FILLED, CANCELLED, REJECTED отменить нельзя.

## 7. Уведомления

### 7.1. Просмотр уведомлений

Вкладка **"Alerts"** отображает список событий:

| Тип | Иконка | Описание |
|---|---|---|
| ORDER_FILLED | Галочка | Ордер исполнен |
| ORDER_CANCELLED | Крестик | Ордер отменён |
| SYNC_ERROR | Предупреждение | Ошибка синхронизации |
| PRICE_ALERT | График | Ценовой алерт |

### 7.2. Непрочитанные уведомления

- Непрочитанные уведомления выделены **синей полосой** слева и **синей точкой** справа.
- Бейдж на вкладке **"Alerts"** показывает количество непрочитанных.

### 7.3. Отметка о прочтении

Нажмите на уведомление — оно будет автоматически отмечено как прочитанное.

Потяните список вниз (pull-to-refresh) для обновления.

## 8. Частые вопросы и устранение неполадок

### Не могу войти в аккаунт

- Убедитесь, что email и пароль введены правильно.
- Если вы забыли пароль — в текущей версии функция восстановления не реализована. Обратитесь к администратору.

### Портфель показывает "No assets in portfolio yet"

- Убедитесь, что подключён хотя бы один брокерский счёт.
- Выполните ручную синхронизацию (кнопка "Sync" на вкладке Accounts).

### Ордер остаётся в статусе PENDING

- Брокер ещё не обработал заявку. Дождитесь обновления статуса.
- Если статус не меняется длительное время — выполните синхронизацию.

### Ошибка "Network Error"

- Проверьте интернет-соединение.
- Убедитесь, что сервер запущен и доступен.

### Данные по счёту устарели

- Выполните ручную синхронизацию (кнопка "Sync").
- Автоматическая синхронизация выполняется каждые 15 минут.
