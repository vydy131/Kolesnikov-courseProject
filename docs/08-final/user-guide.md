# Руководство пользователя

## Начало работы

### 1. Регистрация
1. Откройте приложение InvestAgg
2. На экране входа нажмите "Don't have an account? Register"
3. Введите email и пароль (минимум 8 символов)
4. Нажмите "Register"
5. После регистрации произойдёт автоматический вход

### 2. Вход
1. Введите email и пароль
2. Нажмите "Sign In"
3. Токен сохраняется автоматически — при следующем запуске вход повторять не нужно

## Основные функции

### Портфель (вкладка Portfolio)
- Отображает общую стоимость всех активов
- P&L (прибыль/убыток) в рублях и процентах
- Список активов с текущими ценами
- Потяните вниз для обновления данных

### Счета (вкладка Accounts)
- Список привязанных брокерских счетов
- **Sync** — ручная синхронизация данных от брокера
- **Disconnect** — отключение счёта (с подтверждением)
- Кнопка "+ Connect Broker" для подключения нового счёта

### Подключение счёта
1. Нажмите "+ Connect Broker"
2. Выберите брокера из списка
3. Введите номер счёта и API-токен
4. Нажмите "Connect Account"

### Ордера (вкладка Orders)
- Список всех торговых заявок
- Цветовая индикация: оранжевый (ожидание), зелёный (исполнен), серый (отменён), красный (отклонён)
- Для ожидающих ордеров доступна кнопка "Cancel Order"

### Создание ордера
1. Перейдите к экрану торговли
2. Выберите BUY или SELL
3. Введите тикер (например, SBER)
4. Укажите количество и цену
5. Проверьте итоговую сумму
6. Нажмите "Place Order"

### Уведомления (вкладка Alerts)
- Список событий: исполнение ордеров, ошибки синхронизации, ценовые алерты
- Непрочитанные выделены синей полосой
- Нажмите на уведомление для отметки о прочтении
- Бейдж на табе показывает количество непрочитанных
