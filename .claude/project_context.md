# Investment Aggregator Platform

## Stack
Frontend:
- React Native
- TypeScript
- MobX

Backend:
- Java 17+
- Spring Boot
- Spring Data JPA
- PostgreSQL
- REST + OpenAPI
- JWT Security
- Gradle

## Architecture
PCMEF (distributed client-server)

Client:
- Presentation
- State Management
- API Client
- Local Cache

Server:
- Control
- Mediator
- Entity
- Foundation

## Main goal
Aggregate multiple brokerage accounts into one unified analytics platform.
